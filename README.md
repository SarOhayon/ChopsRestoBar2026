# Chops Resto-Bar website

Website for Chops 2020 Restobar, a kosher Asian fusion steakhouse and sushi bar at 5322 Queen Mary Rd, Montréal.

- `index.html`: the whole site (English/French toggle built in)
- `wordmark.png`: the green CHOPS logo
- `food/`: dish photos

Online ordering links to the UEAT ordering page: https://chopsrestobar.order-online.ai
